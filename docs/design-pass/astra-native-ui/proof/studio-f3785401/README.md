# Native equipment review

An iPhone 18 Pro simulator running the production renderer from `f3785401` produced all twenty loadouts and the environment probe after clearing its render cache. The comparison includes the untouched Astra 03 concept, the app’s 225 lb bar and the same mixed-unit load assembled and exploded.

[Reference and live bar](source-and-studio.jpg) · [All twenty loadouts](loadout-matrix.jpg)

The native frames cover all eleven equipment themes, both units, an unloaded bar, collars, a five-plate stack and a 0.625 kg change plate. Plate count, mass, order and the number printed on each disc come from the loadout. The narrower change plates can be inspected individually in the exploded view.

The live camera shows more of the platform than the source camera. At phone size the blue faces have less contrast and the chrome highlights are narrower than in the original study. These images document the current visual difference for design review.
