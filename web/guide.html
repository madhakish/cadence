Getting started

How to use Cadence

About ten minutes end to end, and most of that is entering honest starting weights. Everything below works the same in the iOS app and the web app unless it says otherwise.

1. Get it on your phone

The web app needs no install and no account — but adding it to your home screen is worth doing, because that's what makes it open full-screen and work in a basement with no signal.

iPhone or iPad (Safari)

  1. Open the web app in Safari — not Chrome, which can't install web apps on iOS.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then Add.

Prefer the native app? See iOS & beta.

Android (Chrome)

  1. Open the web app in Chrome.
  2. Open the ⋮ menu.
  3. Tap Add to Home screen or Install app.

A native Android client is planned; the installed web app is the recommended way to train on Android today.

Desktop

  1. Just open the web app — it works in any modern browser.
  2. Chrome and Edge offer an Install button in the address bar if you want it in its own window.

Handy for building programs with a keyboard before you take them to the gym.

Each install is its own logbook. There's no sync service, so the web app on your laptop and the app on your phone are separate stores. Moving between them is a deliberate act: export a backup on one, import it on the other. Same file format on every platform.

2. Tell it what your gym owns

This is the step people skip, and it's the one that makes the plate math trustworthy.

Open Settings → Gyms

A default gym is already there. Edit it — or add the gyms you actually train at — and set the bars available (45 lb, 35 lb, 20 kg, 15 kg) and how many of each plate the racks hold.

Be honest about pairs

If there are only two 25s in the building, say two. Cadence solves loading against that inventory, so an honest count is the difference between a prescription you can load and one you can't.

Set your display unit

Settings chooses whether you see pounds or kilograms. Entry accepts either regardless — everything is stored canonically in pounds and converted only for display, so switching units never rewrites your history.

3. Create a program

Open Settings → Programs and tap + Add program. Pick a ready-made style, a published methodology, or a blank program you lay out yourself.

What ships as a starting point. All of it stays editable.
StyleDaysWhat it is
Strength — Upper/Lower 4 Barbell strength A/B split. The upper days alternate the overhead and incline presses; every day carries core work.
Olympic Weightlifting 3 Snatch day, clean & jerk day, strength day, with pulls and a squat base.
Metabolic Conditioning 3 Circuits and engine work. Loads hold steady and progression comes from added reps, which is the right progression for conditioning.
Published methodologies varies Novice linear progression, Texas Method, 5/3/1 and conjugate, automated deterministically and initialised from your recorded history.
Blank program — Your days, your lifts, your accessories.
Do this before day one: template baselines are deliberately light, because the app can't know how strong you are. Open the program, then each day, and set every lift's Rotation-1 base to a weight you can confidently handle for the week-1 volume prescription, and Est. 1RM to your rough max. Ten minutes here saves a wasted first cycle.
The first program you create becomes Active automatically. Later ones are created inactive so they can't hijack your Today screen — activate one from its editor when you're ready to switch.

4. Run a training day

The Today screen shows the active program's next day, with every prescription pre-filled.

Preview it, open it, then start the clock

Tap the day's name to read the whole workout — every lift, its prescription and its bar loadout — without committing to anything. Start, on the card or the preview, opens the session for logging; if one is already open it resumes that rather than creating a duplicate.

Timing is a separate, deliberate step. The logger opens showing not started, so reading the plan in the changing room never invents a two-hour workout — Start workout, in the bottom bar or the session menu, is what begins the clock. Started it by accident? Reset to not started puts it back and leaves your logged sets alone, and a session that was never started banks without an invented duration (on iOS, without writing a Health workout either).

Confirm sets as you do them

Warmups arrive pre-filled: bar × 10 then roughly 40/55/70/85 % for barbell work, per-hand steps for main dumbbell lifts, and two bridging steps for a complementary lift that follows the day's main. Work sets stay planned until you mark them completed; mark deliberately omitted work skipped. Only completed work counts toward history and progression.

Enter weights in kg or lb — whichever you typed is remembered, and the value is stored in pounds underneath.

Adjust without losing anything

Add or remove single sets with + Set / − Set. In the set sheet, apply reps to remaining planned sets and apply weight to remaining planned sets are two independent opt-ins, both off by default — so editing reps can't reset a weight you chose on purpose, and opening a set just to add a body flag changes nothing else. Completed and skipped sets are never rewritten.

Grade it honestly

Clean, grindy and wobble are one optional, mutually exclusive assessment; stopped early is independent of it. These aren't judgements — they're the data the autoregulation actually runs on.

If the weight isn't there today, use Dropping load rather than quietly editing the number. Cadence loads a pre-computed fallback and records the reason (bar speed, wobble, joint, heat, fatigue, not there).

Let the rest timer pick the rest

An exercise's own rest setting wins; then its role today (complementary lifts and accessories rest less than a top main); then its movement type. Roughly 5:00 after main work and 1:30 after accessories. Add or subtract a minute mid-rest with +1:00 / −1:00.

On iOS the countdown appears as a Live Activity on the Lock Screen and Dynamic Island, and can be started or skipped from Control Center or the Action Button.

Finish and read the summary

Total volume, top sets, and auto-detected milestones: heaviest set, first time at a rep scheme, and volume records. The next rotation is computed from what you performed, so there is nothing to reconcile before next time.

Training something off-programme? Blank session logs anything, and standalone tracked lifts get their own suggestions under "Next up".

5. The plate calculator

The floating button sits over every tab, because you need it while standing at a rack holding a phone in one hand.

Target → loading

Type the total you want in lb or kg. Cadence returns the per-side loading from the current gym's inventory — mixing a kg plate and an lb plate on the same side when that's genuinely the closest you can get — and shows the achieved total in both units. If the rack can't get within 2 lb of the target, it says so instead of pretending.

Loading → total

Reverse mode: tap in the plates already on the bar and get the total. Useful for taking over a bar somebody else loaded, and for checking a gym's plates are actually the weight they're painted.

6. The rest of the tabs

History

Every banked session, plus a progression chart that keeps main and complementary work on separate lines rather than averaging two different jobs into one trend. Volume keeps its own scale.

Body

A private on-device bodyweight chart with optional annotations, and a protein quick-log against a target you set. No targets are assumed for you.

Signals

Optional shoulder, hip and knee flags attached to individual sets, shown as a per-site timeline you can still read months later — plus an optional next-morning knee check-in after you run.

Gym tag

Store a photo of the membership barcode per gym, shown full-screen straight from the launch screen. On iOS Cadence takes the screen to maximum brightness for you and restores it afterwards; the web app keeps the screen awake and asks you to turn brightness up, because a browser isn't allowed to set it.

Exercise library

141 generic strength, accessory, bodyweight, Olympic and conditioning movements, searchable and categorised, each showing what it works and where it appears in your programs. Add your own freely.

Swaps

Substitute a lift when the rack is taken. Swaps are rule-checked so the replacement does a comparable job, and can apply to today only or to the rest of the cycle.

7. Back it up — this one matters

Cadence has no cloud copy of your training. That's the point, and it means backups are genuinely your responsibility.

Export

Settings → Data → Export JSON writes the full bundle: sessions, programs and their mid-cycle state, tracked lifts, body log, protein, check-ins, milestones, gyms, your exercise library and settings.

Export CSV flattens sessions for a spreadsheet. It is not a backup — it can't be imported again.

Do it after a PR day. The JSON is plain text; keep it wherever you keep files you care about.

Restore

Settings → Data → Import and pick a backup JSON. The format is identical on both platforms, so an iOS export restores into the web app and vice versa — that's also how you move to a new device.

Restore is transactional and per-section: a malformed file aborts without touching your data, and only the sections present in the bundle are replaced. A backup from a newer version is refused rather than half-applied.

Web app users, read this one. iOS Safari can evict local storage for sites you haven't opened in a while. The app also keeps the last three local recovery checkpoints, but those live in the same storage — clearing site data or deleting the app takes them with it. An exported JSON file somewhere else is the only real backup.
